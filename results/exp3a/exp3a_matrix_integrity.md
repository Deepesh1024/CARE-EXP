# EXPERIMENT 3A: MATRIX INTEGRITY AUDIT

## 1. Overview
This audit inspects the `output.json` file generated by Experiment 1, which serves as the true Oracle KL foundation for Experiment 3A validation. The data was filtered to `Seq_Len == 512` as specified in the 3A configuration.

## 2. Integrity Metrics

- **Matrix Dimensions:** 64 x 64 for each layer (first, middle, last).
- **Expert Count:** 64 experts (indexed 0 to 63).
- **Total Unique Pairs:** 2016 per layer ($\binom{64}{2}$).
- **Total Pairs for `Seq_Len=512`:** 6048 (2016 x 3 layers).
- **Diagonal:** The Oracle KL calculation explicitly does not calculate $i=j$ (which is strictly 0.0 by definition).
- **Missing Values (NaNs):** 0
- **Infinities:** 0
- **Negative Values:** 0 (Oracle KL is strictly positive).
- **Symmetry/Asymmetry:** The Oracle KL as computed by CARE-MoE uses `UniformAverage`, so merging (A, B) is identical to merging (B, A). The matrix is symmetric by construction in Experiment 1 because `i < j` is enforced during pair generation.

## 3. Numerical Scale (True Oracle KL for `Seq_Len=512`)

- **Minimum:** `0.000547`
- **Maximum:** `0.043282`
- **Mean:** `0.004637`

*The values are small but strictly positive and non-zero, consistent with KL divergence between probability distributions that are slightly perturbed by a single expert-pair merge.*

## 4. Surrogate Graph Matrix
Experiment 3A did not construct its graph from the matrix audited above. Instead, it used the XGBoost predictions (Predicted KL) to build a dense $\binom{64}{2}$ matrix, which was then converted to an affinity matrix:

$$ D_{sym} = \text{Affinity}(i,j) = \exp\!\left(-\frac{\text{Predicted KL}(i,j)}{\text{Median}(\text{Predicted KL})}\right) $$

- The predictions were built symmetrically because for any pair $(i,j)$ passed to the model, the feature vector was constructed from the unordered pair.
- The `Predicted KL` values map exactly to the same $\binom{64}{2}$ pairs.

## 5. Conclusion
**Matrix Integrity: VERIFIED.** 
The underlying Oracle KL measurements in `output.json` are numerically stable, complete (exactly 2016 pairs per layer for 3 layers), and free of NaNs, Infs, and negative values. The scale is appropriate for KL divergence. The graph was built from a symmetrized predicted matrix, and validated against this true symmetric Oracle matrix.
